2. 画面の見方

番号 名前 内容

② ツールオプション 今のツールの設定。リグツールではモード切り替え・バインド・プリセットなどがここに出ます。1段に収まらないときは、下の段がキャンバスの上に重なって出ます(キャンバスの位置は動きません)

⑨ レイヤー レイヤーの一覧。目のアイコンで表示/非表示、鍵でロック。名前はダブルクリックで変更
⑩ タイムライン アニメーションのフレーム一覧と再生・書き出し(8章)

タブ(絵を何枚も同時に開く)

キャンバスの上にタブが並び、絵を何枚も同時に開いておけます。今描いている絵はそのままで、別の絵を描き進められます。

  • 「新規」「開く」は新しいタブで開きます(今の絵は消えません)。今のタブが何も描いていない「無題」なら、そのタブを使います。同じファイルをもう開いているときは、そのタブに切り替わります
  • タブをクリックで切り替え。×(または中ボタンのクリック)で閉じます。保存していない変更があると、閉じる前に聞かれます
  • ● = 保存していない変更があるタブ。**「フォント」**の印 = フォント作成のタブ(13章)
  • タブはドラッグで並べ替えられます。右の ＋ で新しい絵
  • 元に戻す(Ctrl+Z)・拡大率・表示位置・選んでいる図形は、タブごとに覚えています
  • タブをまたいでコピー&ペーストできます。絵のタブで図形を選んで Ctrl+C → ほかのタブに切り替えて Ctrl+V(3.7)
  • キー: Ctrl+Tab / Ctrl+Shift+Tab で次 / 前のタブ、Ctrl+W で今のタブを閉じる(メニューの ファイル にも)
  • Kodai を閉じるときは、保存していないタブを1つずつ確かめます。次に起動したときは「無題」1枚から始まります

画面の比率を変える

  • ① キャンバスとタイムラインの境目を上下にドラッグすると、タイムラインの高さが変わります。下げるとキャンバスが広くなります。ダブルクリックでタイムラインをたたむ / 戻す
  • ② キャンバスとサイドバーの境目を左右にドラッグすると、サイドバーの幅が変わります(ダブルクリックで元の幅)
  • ③ 右のパネル(カラー・線と塗り・整列など)は、見出しをクリックするとたためます
  • 右のパネルが画面に入りきらないときは、サイドバーをスクロールできます(上の画面全体の図は、カラーと整列をたたんだ状態です)
  • 大きさ・たたんだパネルは次に起動したときもそのままです

レイアウト(ボタンの位置を変える)

上のバーのボタン(新規・開く・保存…)と、左のツールバーのツールは、持って好きな所へ動かせます。よく使う機能のボタンを足したり、使わないボタンを外したりもできます。

  1. 右上の 「レイアウト」 を押します(メニューの 表示 →「レイアウト(ボタンの位置を変える)」でも)。
  2. ボタンのまわりに点線が出ます。ボタンを持って(ドラッグして)、上のバーか左のツールバーの好きな所で離します。青い線の所に入ります。
    • 上のバーのボタンを左のツールバーへ、ツールを上のバーへ、と入れ替えることもできます。
  3. 下の箱には、置いていない機能のボタンが並んでいます(トレース・GIF書き出し・コピー・グループ化・テクスチャ など)。持ってバーへ入れると、足せます。
  4. バーのボタンを下の箱へ入れると、外せます。「区切りの線」は、いくつでも置けます。
  5. 「完了」(または Esc)で終わります。並びは、次に起動したときもそのままです。
困ったとき こうします
ボタンをなくしてしまった / 元に戻したい 「レイアウト」→ 「はじめの並びに戻す」(メニューの 表示 →「ボタンをはじめの並びに戻す」でも)
ボタンを押しても動かない レイアウトを変えている間は、ボタンは動かすだけです。「完了」を押すと、ふつうに使えます
  • 同じボタンを、いくつでも置けます(上のバーと左のツールバーの両方に、など)。下の箱には、置いてあるボタンも少し薄く出ています
  • レイアウトの帯の「右のパネル…」「色とデザイン…」「チャーム…」で、次の見た目も変えられます(メニューの 表示 にもあります)

右のパネルの並び

カラー・線と塗り・図形の情報・整列・パレット・レイヤーの並び順(▲▼)と、出す / 出さない(チェック)を変えられます。「はじめに戻す」で元どおり。

3. 描く

3.1 レイヤーの種類

種類 アイコン 向いている絵
ベクター ノード 図形・パスで描く絵。1つずつ選んで動かせ、リグで図形ごとに動かし方を変えられる(おすすめ)

3.3 矢印ツールでできること

  • ドラッグで移動、矢印キーで 1px(Shift で 10px)移動
  • 選択枠の角・辺で拡大縮小。Shift で縦横比を保つ(辺のハンドルでも)、Ctrl(または Alt)で中心に向かって縮む / 中心から広がる(Shift と一緒にも使えます)。角の少し外側で回転(Shift で15°単位)
  • Ctrl+G でグループ化、Ctrl+Shift+G で解除。グループは1つの図形として選択・移動・ドット化・バインドできます
  • 右クリックでメニュー(ドット化・角丸・グループ化・左右反転・上下反転・アウトライン化・縁取り・前面へ/背面へ・削除)

3.4 多角形と角丸

多角形ツール(Y)

  1. ツールバーの三角のアイコン(または Y キー)
  2. 図形の中心から外へドラッグ。離れた距離が大きさ、ドラッグの向きが最初の角の向きになります
  3. ドラッグしたまま ↑ キー(またはホイールを上へ)で角が増え、↓ キー(ホイールを下へ)で減ります。三角形 → 四角形 → 五角形 → 六角形 …(最大20)
  4. Shift を押しながらだと、角がまっすぐ上を向きます
  5. 角の数はツールオプションの「角の数」でも変えられます(次に描くときもその数から始まります)

できた多角形はふつうのパスなので、線と塗り・アウトライン化・縁取り・ドット化・リグがそのまま使えます。

角丸(かどまる)

  1. 矢印ツール(V)で四角・多角形・パスを選ぶ(複数・グループも可)
  2. 右クリック → メニューの ① 「角丸」 のスライダーを動かす(数字を入れても OK。単位は px)
  3. 動かしている間、その場で角が丸くなります。0 に戻せば元の角に戻ります(あとから何度でも変えられます)
  • 丸くなるのは「直線と直線がつながる角」です。曲線の部分はそのまま
  • 辺が短いときは、はみ出さないように自動で小さめに丸めます
  • Ctrl+Z で1回ぶん元に戻せます

3.5 整列

矢印ツールで図形を2つ以上選んで、右の「整列」パネルのボタンを押します。

番号 内容
① ② ③ 左 / 左右の中央 / 右にそろえる
④ 上 / 上下の中央 / 下にそろえる、横に等間隔 / 縦に等間隔(3つ以上のとき。図形どうしのすき間を同じにする。基準が選択範囲なら両端の図形は動かさず、アートボードならアートボードの端から端まで広げて並べる)
⑤ 基準: 選択範囲(選んだ図形全体の枠に合わせる)/ アートボード(アートボードの端・中央に合わせる)
  • 図形が1つだけのときは、自動でアートボードに合わせます(例: 1つ選んで「左右中央」→ アートボードの真ん中へ)
  • 線の太さも含めた見た目の端でそろえます。曲線は、曲線そのものの端で測ります(アイコンや丸い形もぴったりそろいます)
  • グループは1つの図形としてそろいます。Ctrl+Z 1回で元に戻せます

パスファインダー(図形の合体・型抜き)

図形を 2つ以上 選ぶと、整列パネルの下の ① パスファインダー のボタン(右クリックメニューにもあります)で、図形の形を組み合わせて 1つのパス にできます(イラストレーターと同じ4つ)。

ボタン できる形 色
合体 全部をまとめた1つの形 一番前の図形の色
前面で型抜き 一番後ろの図形から、前の図形の形を抜いた形 一番後ろの図形の色
交差 全部が重なっている所だけ 一番前の図形の色
中マド 重なっている所を抜いた形(奇数枚が重なる所だけ残る) 一番前の図形の色
  • 形として使うのは、四角・楕円・多角形・閉じたパス・文字は 中身(塗りがなくても形の内側)、直線・開いたパスは 線の太さの範囲 です
  • グループは中身全部で1つの図形として扱います
  • 穴のある形になったら、穴のあいた1つのパス(複合パス)になります。元に戻す(Ctrl+Z)で元の図形に戻ります
  • アウトライン化と同じく、形を細かくなぞって作るので、点の位置は元の図形とぴったり同じではありません(見た目はほぼ同じ)。点は、角と、曲線の上下左右の端を中心に、少ない数にまとめます

3.6 文字ツールとフォント

  1. ⑥ 文字ツール(K)を選んで、キャンバスをクリック
  2. そのまま文字を入力(Enter で改行)。Esc か、ほかの場所をクリックで終わり(何も書かなければ消えます)
  3. 書いた文字をもう一度クリック(矢印ツールならダブルクリック)で書き直し
番号 内容
① フォント: 「Kodai のフォント」(商用利用OK)と「取り込んだ・作ったフォント」から選ぶ
② ＋フォント: TTF・OTF・WOFF のフォントファイルを取り込む。取り込んだフォントは次回からも使えます
③ サイズ(px)
④ 行間(文字の大きさの何倍か)・字間(全部の字の、文字と文字の間。px)
— カーニング・ベースライン(入力しているときだけ出ます。下の「字ごとの調整」)
⑤ 行のそろえ方(左・中央・右)

3.8 反転(左右・上下・好きな軸)

  1. ツールバーの ① 反転ツール(または F キー)。反転する図形をクリックで選ぶ(Shift+クリックで追加。矢印ツールで選んでおいても OK)
  2. ツールオプションの ② 「左右反転」「上下反転」 でその場で反転。「コピーを左右反転」「コピーを上下反転」 は元の図形を残して、反転したコピーを作ります(左右対称の絵を作るときに便利)
  3. 好きな向きで反転したいときは、キャンバスをドラッグ。③ 基準点(十字の丸)からマウスへの向きが反転の軸(点線)になり、離すと反転します
    • Shift を押しながら: 軸が 45°単位(横・斜め・縦)
    • Alt を押しながら: 反転したコピーを作る(元の図形はそのまま)
  4. 基準点ははじめは図形の真ん中。何もない所(または選んだ図形の上)をクリックすると、基準点をそこに置けます。ボタンの反転もその点で行います。「基準点を中心に戻す」(または Esc)で真ん中に戻ります
  • ラスターレイヤーでは、レイヤーの絵全体を反転します。左右・上下・45°の反転ではドットがぼけません
  • 四角・楕円は左右・上下の反転なら四角・楕円のまま。斜めの軸で反転するとパスになります
  • 文字は鏡に映した字になります。グラデーション・グラデーションでドット化の向きも一緒に反転します
  • 矢印ツールの右クリックメニュー・ツールオプションにも「左右反転」「上下反転」があります(こちらは図形の真ん中で反転)
  • Ctrl+Z で元に戻せます

  • 入っているもの: 道具(歯車・スパナ・ハンマー・ドライバー・ペン・鉛筆・筆・はさみ・定規・消しゴム・磁石・鍵・フラスコ・薬・爆弾…)、画面の操作(家・虫眼鏡・メニュー・閉じる・プラス・チェック・矢印・更新・保存・フォルダ・ゴミ箱・目・情報・注意・はてな…)、メディア(カメラ・画像・音符・マイク・再生・ゲームパッド・サイコロ…)、しるし(ハート・星・旗・王冠・盾・剣・トロフィー・コイン・プレゼント…)、乗り物、天気・自然(太陽・月・雲・雨・雪・稲妻・炎・水滴・葉・木・花・山)など
  • 置いたものはふつうのパスです。矢印ツールで動かす・大きさを変える、ダイレクト選択で形を直す、ドット化・縁取りもできます
  • アイコンの形の一部は、Feather Icons(MIT)・Lucide(ISC)という無料のアイコン集を参考にしています。どちらも商用利用でき、アイコンを使った作品に表記は要りません(Kodai を配るときのライセンスの文は src/vendor/ICONS-LICENSE.txt)

3.20 曲げるツールとスマートガイド

① 曲げるツール(C)

まっすぐな線を、きれいに曲げられます。

  • 図形の線(辺)の上をドラッグすると、つかんだ所がマウスの位置を通るように曲がります。もう曲がっている線は、その曲がりからさらに曲げられます
  • Shift を押しながらドラッグすると、線の両はしとマウスの位置の3点を通る、ぴったりの円弧になります。四角の右の辺を、辺の高さの半分だけ外へ引くと半円(上の図)
  • Alt+クリックで、その線をまっすぐに戻します
  • 四角・楕円・直線は、曲げるとパス(点の集まり)になります。グループの中の図形も曲げられます。Ctrl+Z で元に戻せます

③ 2本の辺をつなぐ(曲げるツールでクリック2回)

2つの図形の辺を、なめらかな線でつないで1つの図形にできます。

  • 曲げるツールで、1本目の辺をクリック(ドラッグしない)すると、その辺が青く光ります(上の図の ①)
  • 続けて、ほかの図形の辺をクリックすると、2つの図形が1つのパスになり、曲がった管のようにつながります(②)
    • 上下に重ねた四角の右の辺どうし → 右が半円になります(つなぎ目の線も消えます)
    • すき間をあけて並べた2本の棒 → 外側は大きな半円、内側も小さな半円で丸くなります(③)
    • 横の棒と縦の棒(L の字)→ 90° の角丸になります。内側の角も、同じ中心で丸くなります
    • 曲がるのは1か所だけです。角まで届いていない方の棒は、まっすぐのばしてから曲がります(④。ほかの所はまっすぐのまま)
    • 開いた線どうし → クリックした所に近い方のはしどうしが、U の字のようにつながります
  • 色は、1本目にクリックした図形の色になります。Ctrl+Z で元に戻せます
  • やめるときは、同じ辺をもう一度クリック、何もない所をクリック、または Esc
  • 同じ図形の中の辺どうしは、つなげません

② スマートガイド(動かすときに、ほかの図形にそろう)

矢印ツールで図形を動かすと、ほかの図形やアートボードの端・中心に近づいたところで吸い付き、ピンクの線と「図形の中心」「アートボードの中心」「図形の左端」などの文字が出ます(どこにそろったかが分かります)。

  • そろう所: ほかの図形(見えているベクターレイヤーの図形すべて)とアートボードの、左端・中心・右端 / 上端・中心・下端。ガイドにも吸い付きます(近い方)
  • Alt を押しながら動かすと、吸い付きません
  • Shift を押しながら動かすと、**まっすぐ(横・縦・45°)**にだけ動きます。横に動かしているときは、横の向きにだけ吸い付きます
  • メニューの 表示 →「スマートガイド」で、オン / オフ

4. 線と塗り

図形には 「線」(ふち) と 「塗り」(中身) の2つの色があります。右側の「線と塗り」パネルで見たり変えたりできます。

番号 内容
① 塗りの色。クリックすると色を選べます。選んでいる間、図形の色がその場で変わります
② 「なし」: 塗りを消す(線だけの図形にする)。線の行の「なし」は線を消す
③ 線の色(枠だけの四角が「線」の印)
④ 線幅。スライダーか数字で。複数の図形を選んでいればまとめて変わります
⑤ 入れ替え: 線の色と塗りの色を入れ替え
⑥ アウトライン化(5章)
⑦ 縁取り…(6章)
  • 図形を選んでいるとき: 選んだ図形の色が表示されます(右上に「選択中の図形 ○個」)。グループを選べば中の図形すべてが対象。色が図形ごとに違うときは「(混在)」と出ます
  • 何も選んでいないとき: 「新しい図形」の設定になります。これから描く図形の線 = メインカラー、塗り = サブカラー、線幅
  • 次に作る図形は、前の図形の色を引き継ぎます。例: 赤い円を作って色を変えたあとに三角を作ると、三角も同じ色(線幅・グラデーションも)
  • パレット・最近使った色をクリックすると、選んでいる図形の色がすぐ変わります。塗りと線のどちらが変わるかは、パネルの「塗り」か「線」の行をクリックして選びます(選んでいる行が青く光ります。既定は塗り)。右クリックすると反対の方が変わります。図形を選んでいないときは、これまでどおりメイン / サブの色になります
  • スポイトのボタン(塗り・線の行の右、カラーパネルの色の横): 押してからキャンバスの色をクリックすると、その色になります(小さい拡大鏡が出ます。Esc でやめる)
  • カラーパネルのメイン / サブの色の四角は、ふだんは出していません。「設定」→「操作」の「カラーパネルにメイン / サブの色を出す」で出せます
  • 変更はすべて Ctrl+Z で元に戻せます

塗りつぶしツール(G)で色を付ける

ベクターレイヤーでは、形の内側ならどこをクリックしてもその図形の塗りが変わります(ふちを狙う必要はありません)。

  • 左クリック: メインカラーで塗る / 右クリック: サブカラーで塗る
  • Shift+クリック: 線の色を変える
  • グループの中の図形も1つずつ塗れます
  • 重なっているときは一番上の図形が塗られます

あいまいな塗り(線が少し切れていても塗れる)

ペンで描いた線のように、きっちり閉じていない線で囲んだ所も、中をクリックすれば塗れます(Kaiju のバケツと同じ仕組みです)。

  • ベクターレイヤー: 図形のない所(線で囲まれた所)をクリックすると、その範囲が 「塗りのパス」 として作られ、線の下に入ります。あとで矢印ツールで選んで、色や形を変えられます。作った塗りをもう一度クリックすると、色だけ変わります。
  • ラスターレイヤー: 囲まれた所が、今のレイヤーに塗られます。線を描いたレイヤーとは別のレイヤーに塗れます(線はそのまま残ります)。

塗りつぶしツールを選ぶと、上のバーに設定が出ます(①)。

設定 内容
隙間閉じ 線の切れ目がこの幅(px)より狭ければ、そこからもれずに塗れます。はじめは 10。0 にすると、ふつうのバケツ(切れ目からもれる)。細いとがった所に塗り残しが出るときは、小さくします
線へのはみ出し 塗る範囲をこの幅(px)だけ広げて、線の下にもぐらせます(線とのあいだに、すき間が残りません)。はじめは 2
色の許容 大きいほど、似た色まで広く塗ります。はじめは 32
見えている絵ぜんぶを境目に オン(はじめ): ほかのレイヤーの線も境目にします / オフ: 今のレイヤーの絵だけを境目にします
隣接ピクセルのみ(ラスター) オフにすると、つながっていなくても、似た色の所ぜんぶを塗ります(このときは、隙間閉じ・はみ出しは使いません)
  • 大きく開いた線(「C」の形など)の内側をクリックしたときは、今までどおり、その線の図形が塗られます。

グラデーション(塗り・線)

図形を選ぶと、塗り・線それぞれの下に ① 単色 / 線形 / 円形 のボタンが出ます。「線形」「円形」でグラデーションになります。

番号 内容
① 単色 / 線形(まっすぐ変わる)/ 円形(中心から外へ変わる)
② 色の帯。下の四角が色の点。点をドラッグで位置を変える、帯をクリックで点を追加(その場所の色で)
③ 選んだ点の 色(四角をクリック)・不透明度(%)・点を削除(3つ以上のとき)・反転(色の並びを逆に)
④ 線形は 角度(0° = 左 → 右、90° = 上 → 下)。円形は 中心の位置(横・縦)と大きさ
  • グラデーションは図形の大きさに合わせて付くので、移動・拡大縮小・リグで動かしても付いてきます。矢印ツールで回すと向きも回ります
  • 上の単色の四角で色を選ぶと、単色に戻ります
  • ドット化と組み合わせると、グラデーションもドットの色になります(下の「グラデーションでドット化」も)
  • 文字にはまだグラデーションを付けられません(アウトライン化してパスにすれば付けられます)

5. パスのアウトライン化(線 → 塗り)

「線」を、同じ見た目の「塗り」の図形に変換します(イラストレーターの「パスのアウトライン」と同じ)。 線の太さに頼らず、パスの形だけで絵を成立させたいときに使います。

使い方: 矢印ツールで図形を選ぶ(複数・グループも可)→ 次のどれか

  • 「線と塗り」パネルの アウトライン化 ボタン
  • 右クリック →「パスのアウトライン化」
  • Ctrl+Shift+O(メニュー「編集」にもあります)

点は少なくまとまります: できたパスの点(アンカーポイント)は、角と、曲線の上下左右の端を中心に置きます。丸い線なら外側 4点 + 内側 4点、「o」の字も同じです。 まっすぐな辺は、両端の角だけになります。形は細かくなぞってから曲線を当てはめるので、元の見た目とのずれは、文字なら大きさの 0.2% ほどまでです。

変換のされ方

元の図形 結果
線だけ(直線・開いたパス・塗りなしの形) 線の形をした「塗り」のパス1つ
線と塗りがある 「塗り」の図形と「線だったパス」のグループ
輪になった線(円の線など) 穴のあいたパス(複合パス)
文字 字の形のパス
ドット化した図形(図形・グループ・レイヤーのドット化) ドットの形そのままのパス(カクカクの形。色ごとに1つのパス)
  • 変換後は線幅を変えても太さは変わりません(形そのものになったため)。太さを変えたいときは変換前に
  • 変換したパスにさらに線を付けたり、ドット化・リグで動かしたりもできます
  • リグのバインドの設定は引き継がれます
  • ドット化した図形は、見えているドットの形のまま(マス目の角だけの直線のパス)になります。塗りと線の境目のにじんだ色は、塗りか線のどちらかの色にそろいます(7章)

6. 縁取り(外形のフチを一発で作る)

選んだ図形やグループ全体の外形(シルエット)をなぞったパスを新しく作ります。キャラクターの外側にフチを付けるときなどに。

使い方: 矢印ツールで図形を選ぶ(Ctrl+A ですべて)→「線と塗り」の 縁取り…(または右クリック / Ctrl+Shift+B)

設定 内容
太さ 外側に広げる幅(px)
色 縁の色(はじめはメインカラー)
フチ(塗りの図形) 外形を太さぶん広げた「塗り」の図形を、選んだ図形のすぐ後ろに置く(ふつうはこちら)
線(あとで線幅で調整) 外形に沿った「線」のパスを後ろに置く。線幅 = 太さ×2 で、内側の半分は絵に隠れる。あとから「線と塗り」の線幅で太さを調整しやすい
内側のすき間(穴)にも縁を付ける オフ: 一番外側だけ(シルエット)。オン: 腕と体のすき間のような「穴」のふちにも付ける
選んだ図形ごとに別々に作る オフ: 全体で1つ。オン: 図形(グループ)ごとに1つずつ作って、それぞれのすぐ後ろに置く

  • 作った縁取りは選択された状態になるので、そのまま「線と塗り」で色を変えられます
  • リグで動かすキャラは「図形ごとに別々に作る」がおすすめ。縁取りは元の図形のバインドを引き継ぐので、腕のフチは腕と一緒に動きます(全体で1つの縁取りはレイヤーのバインドに従います)

7. ドット化

選んだ図形・グループ、またはレイヤー全体を、あとから戻せる「ドット風」にできます。

  • 粗さは 192段階。左端が「なし」、1段階目は 1px(変わったのが分からないくらいの細かいギザギザ)、右端は 64px。細かい所ほど細かく刻んであるので、少しずつドットにしていけます
  • ツールオプションのスライダー: 図形を選んでいなければ「レイヤーのドット化」。横にドットの大きさ(px)が出ます
  • Alt+ホイール: 4段階ずつ粗く/細かく
  • 右クリックメニュー: スライダーと なし/1/2/4/8/16/32px のボタン
  • ドット化した図形をアウトライン化すると、ドットの形のままのパスになります(上の画像の右。5章)
  • ドットの格子は全体でそろうので、隣り合う図形のドットの位置が合います
  • リグで動かしてもドット感のまま動き、書き出しを拡大してもぼけません

グラデーションでドット化(粗さが変わるドット・網点)

図形(何も選ばなければレイヤー全体)を右クリック →「グラデーションでドット化…」で、場所によって粗さが変わるドットにできます。設定の画面は右側に出て、キャンバスを見ながら値を動かせます(ホイールでズームもできます)。

項目 内容
四角いドット ドットの粗さが、向きに沿って「始め」から「終わり」へだんだん変わる
網点 丸いドット(マンガのトーン風)。粗さに加えて 丸の大きさ も「始め」から「終わり」へ変わる(100% = マスいっぱい)
粗くなる向き 角度(0° = 左 → 右、90° = 上 → 下 …)。矢印のボタンで8方向にすぐ合わせられる。斜めにすると、ドットの並びごとその角度に回る(網点なら斜めのトーン)
始めの粗さ・終わりの粗さ ふつうのドット化と同じ 192段階。0 にするとその端はイラストのままで、そこから少しずつドットになる
  • 色のグラデーションと組み合わせると、ドットの色もなめらかに変わります
  • ふつうのドット化と同じく 元の形は残る ので、「外す」でいつでも戻せます。ふつうのドット化と両方付けたときは、こちらが優先されます
  • 網点のドットは 3px より細かくなりません
  • アウトライン化(Ctrl+Shift+O)すると、ドット1つずつの形のパスになります(四角いドットは四角、網点は丸)。色ごとに1つのパスで、色のグラデーションがあれば色の数だけパスができます。パスなので、動かしてもドットの形は変わりません

8. アニメーション

8.1 しくみ

  • アニメーションは フレーム(コマ) の並びです。各フレームに 表示時間(ミリ秒) があります
  • 各レイヤーは フレームごとに別の中身 を持ちます。描画ツールは「今のフレーム」に描きます
  • 動かし方は2通りあり、組み合わせもできます
方法 向いているもの 説明
コマ送り(フレームごとに描く) 自由な変化、エフェクト、手描きアニメ 1コマずつ絵を描く(8.3)
リグ(ボーンで動かす) キャラの歩き・走り・手を振る・弾む 絵は1枚だけ描いて、フレームごとのポーズで動かす(9章)

8.2 タイムライン

番号 内容

② 時間: 今のフレームの表示時間(ms)。100ms = 1秒に10コマ。「全フレームに適用」で全部を同じ時間に
③ フレーム操作: +新規(空のフレームを今の後ろに追加 Alt+N)/ 複製(今のフレームをコピー Alt+D)/ ← → 並べ替え / 削除

  • 表示時間はフレームごとに変えられます(決めポーズだけ長く、など)

8.3 コマ送りで描く

  1. 1フレーム目に絵を描く
  2. 複製(Alt+D) で次のフレームを作る(少しだけ変えたいとき)。まっさらから描くなら +新規(Alt+N)
  3. オニオンスキン(Alt+O) をオンにする。前のフレーム(①、赤っぽい)と次のフレーム(③、青っぽい)が薄く見えるので、それを目安に少しずらして描く
  4. 2〜3 をくり返す
  5. Enter で再生して確認。速さは ② の「時間」で調整

  • 注意: ふつうのレイヤーは絵のないフレームでは何も表示されません。動かない背景を全フレームに出したいときは、背景を描き終えてから「複製」でフレームを増やしてください(複製は全レイヤーの絵をコピーします)。単色の背景なら「設定」の背景色が便利です
  • リグにバインドしたレイヤーだけは例外で、絵のないフレームでは直前の絵を使い続けます(9章)

9. リグ(ボーンで動かす)

9.0 ボーンを自動で入れる(パーツ分けした絵)

頭・体・腕・脚などが別々のレイヤーになっている絵なら、ボーンを自分で引かなくても、ボタン1つで入ります。

  1. リグツール(R)を選ぶ
  2. 上のツールオプションの「ボーンを自動で入れる」を押す
  3. ボーンが置かれて、各レイヤーがボーンにつながります(「ボーンに固定」= 紙の人形のように、パーツの形は変えずに回す)
  4. そのまま「歩く(正面)」などの動きのボタンを押すと動きます
決まり
レイヤーの見分け方 まずレイヤーの名前: 頭・顔 / 体・胴 / 腕・手 / 脚・足 / しっぽ、左・右(英語の head / body / arm / leg / foot / tail / left / right も可)。髪・角・耳・目・口などは頭につなぎます
名前で分からないとき 絵の位置から決めます(一番上 = 頭、下のほう = 脚、体の左右 = 腕、残りで一番大きい = 体)
ボーンの置き方 体 = 下 → 上、頭 = 首 → 頭の上、腕・脚・しっぽ = 絵の長い向きの両端のうち、体に近いほうが付け根
左右 名前に左・右がなければ、体の中心より左にあるほうが「左」
  • 今あるボーンは置き換わります(Ctrl+Z で戻せます)。位置が気に入らないボーンは、あとから「ボーン作成」のモードで動かせます
  • レイヤーが1枚しかない絵には使えません。先に「画像読込 → パーツに分ける(AI)」(12章)で分けるか、パーツごとに別のレイヤーに描きます
  • ひじ・ひざで曲げたいときは、そのあと自分で子ボーンを足します(自動で入るのは、腕・脚それぞれ1本)

9.1 リグとは

絵に ボーン(骨) を入れて、ボーンを回すと絵がついてくる仕組みです。絵は1枚描くだけで、歩く・走る・手を振るなどのアニメーションが作れます。

 ① 絵を描く ─→ ② ボーンを作る ─→ ③ 絵とボーンをつなぐ(バインド)
                                            │
 ⑥ 再生・書き出し ←─ ⑤ キーの間は自動で補間 ←─ ④ フレームごとにポーズ(キー)を付ける
                                             (またはプリセットで一発)
  • 元の絵は書き換えません。ボーンやポーズを消せば元に戻ります
  • リグで動くレイヤーは、1フレーム目に描いた絵が全フレームで使われます(絵のないフレームでは直前の絵を使う)
  • 描画ツールで絵を直すときは、そのレイヤーは元の形(ポーズなし)で表示されます

リグツール(R)には3つのモードがあり、ツールオプションの左端で切り替えます。

モード すること
ボーン作成 ボーンを作る・位置を直す(表示はポーズなしの元の形)
ポーズ ボーンを回してポーズを付ける(今のフレームのキーになる)
格子 伸び縮み(スクワッシュ&ストレッチ)用の格子の範囲を決める

9.2 準備: パーツを分けて描く

リグでいちばんきれいに動くのは、動くパーツが別々の図形(またはレイヤー)になっている絵です。

  • 例: 頭・体・左腕・右腕・左脚・右脚を別々の図形で描く。目や口など頭の中身は、頭とグループ化(Ctrl+G)して1つにしておく
  • 手足が体に重なる所は、手足を体の後ろ(背面)に置くと、付け根が曲がってもつなぎ目が見えにくくなります
  • ラスター(ペン)で描いた絵なら、パーツごとにレイヤーを分けます
  • 1枚の絵のままでも「自動」バインドで動きますが、手足が胴体に重なっている所は一緒に引っぱられやすくなります
  • すでに描いてある1枚の絵(PNG・JPG)なら、12章の「パーツに分ける(AI)」でクリックだけでパーツごとのレイヤーにできます

9.3 手順1: ボーンを作る(ボーン作成モード)

リグツール(R)→ ① ボーン作成 にして、キャンバスをドラッグします。

  1. 最初のボーン = ルート(体)。腰(付け根)から首(先端)に向かってドラッグ。付け根に ② の黄色い大きい点が付きます
  2. 頭: 体の先端(首)からドラッグ → 先端につながった子ボーンになります
  3. 腕: 体のボーンを選んだまま(クリックで選択)、肩の位置から手の方向へドラッグ → 体から「離れた子ボーン」になり、③ のように点線で親とつながって表示されます
  4. 脚: 同じように体を選んでから、腰の左右から足先へドラッグ
  5. ひじ・ひざを曲げたいときは、腕のボーンの先端からさらにドラッグして子ボーン(前腕・すね)を作ります
  • 役割(体・頭・左腕・右腕・左脚・右脚・しっぽ・その他)は位置から自動で付きます。違っていたら ④ の「役割」で直してください。プリセットは役割を見て動かすので大事です
  • 名前は ④ の「名前」で変更できます(ボーンの横に表示されます)
  • 「左」「右」は画面で見て左・右です
操作(ボーン作成モード) 結果
何もない所からドラッグ 新しいボーン(ボーンを選んでいればその子)
ボーンの先端からドラッグ つながった子ボーン
ボーンの付け根をドラッグ 付け根だけ動かす
ボーンの胴体をドラッグ そのボーンと子を丸ごと移動
Shift+先端をドラッグ 先端を動かす(長さ・向きを変える。つながった子もついてくる)
Alt+ドラッグ 既存のボーンの上でも必ず新しく作る(横向きキャラの手前と奥の脚を同じ位置に作るとき)
クリック ボーンを選ぶ(オレンジの枠)
Delete / 「削除」 選んだボーンを削除(子は親につなぎ替え)

9.4 手順2: バインド(絵とボーンをつなぐ)

ツールオプションの ① バインド で、絵がどのボーンについていくかを決めます。

  • 矢印ツール(V)で図形を選んでからリグツールに切り替えると、② のその図形だけに設定されます(ラベルが「選択中の図形 ○個」になる)
  • 図形を選んでいなければ レイヤー全体 に設定されます(ラベルが「レイヤー「○○」」)
バインドの種類 動き方 向いているパーツ
なし 動かない 背景など
自動(全部のボーンの近さで変形) 近いボーンほど強く影響を受けて、なめらかに曲がる 1枚絵のキャラ、しっぽ、布
「○○」から先 そのボーンとその子ボーンだけで自動に曲がる 手足(腕 → 前腕 のように曲がる)
「○○」に固定 そのボーンにぴったりついて、形は曲がらない(軽い) 胴体・頭など曲がらないパーツ

設定の優先順位: 図形 > その図形が入っているグループ > レイヤー。 例: レイヤーを「自動」にしておき、頭のグループだけ「頭」に固定、といった使い方ができます。

おすすめの組み合わせ(正面キャラ)

パーツ バインド
頭(目・口とグループ化) 「頭」に固定
体 「体」に固定
左腕 / 右腕 「左腕」から先 / 「右腕」から先
左脚 / 右脚 「左脚」から先 / 「右脚」から先

レイヤーパネルで、バインドしたレイヤーには「リグ」の印が付きます。

9.5 手順3: ポーズとキー(ポーズモード)

① ポーズ モードにして、ボーンをドラッグします。

操作(ポーズモード) 結果
ボーンをドラッグ 付け根を中心に回転(Shift で15°単位)
Alt+ドラッグ ボーンの向きに伸び縮み(0.1〜4倍)
ルート(体)の付け根をドラッグ キャラ全体を移動(ジャンプ・上下の揺れなど)
格子の点をドラッグ 格子で伸び縮み(9.7)

キーと補間

  • ポーズを変えると、今のフレームにキー(◆) が付きます。タイムラインの番号に ◆ が出ます
  • キーのないフレームは、前後のキーから自動で補間されます。上の画像では ◆1(気をつけ)と ◆5(右手を上げる)の間の 3フレーム目が、途中のポーズ(手が横)に自動でなっています
  • ④「キー削除」: 今のフレームのキーを消す(前後から補間されるようになる)。キーがないときは「キーなし」と表示
  • ④「リセット」: 今のフレームを元のポーズ(何も動かしていない状態)のキーにする
  • ツールオプションの「補間」: なめらか(動き始めと終わりがゆっくり)/ 一定の速さ

手でアニメーションを作る流れ(例: 手を振る)

  1. タイムラインで「+新規」を押してフレームを増やす(例: 6フレーム)
  2. 1フレーム目: 「リセット」(気をつけの姿勢のキー)
  3. 3フレーム目: 右腕を上に回す → ◆
  4. 5フレーム目: 右腕を少し戻す → ◆
  5. Enter で再生。間のフレームは自動でつながります

9.6 プリセット(一発で動きを付ける)

ポーズモードの ① プリセット のボタンを押すと、必要な数のフレームを作って、全フレームにポーズのキーを入れます。② のように全フレームに ◆ が付きます。④ の再生(Enter)で確認できます。

プリセット フレーム 必要なもの 内容
歩く(横) 8 役割が「左脚」「右脚」のボーン 横向きキャラの歩き。腕も振る。「右向き/左向き」で向きを選ぶ
走る(横) 6 同上 横向きキャラの走り
歩く(正面) 8 同上 正面向きキャラの歩き(足踏み+体の揺れ)
走る(正面) 6 同上 正面向きキャラの走り
弾む 8 なし(格子を自動で作る) ぴょんぴょん弾む。つぶれて伸びる
待機(呼吸) 8 なし(格子を自動で作る) その場でゆっくり呼吸
  • 何もバインドしていなければ、今のレイヤーを自動で「自動」バインドします
  • ③ オニオンスキンをオンにすると、前後のフレームのポーズが薄く重なって見えます(上の画像)
  • プリセットのあとで、好きなフレームのボーンをドラッグして手直しできます(そのフレームのキーが上書きされます)
  • フレームがプリセットの数より多いときは、余ったフレームに絵がなければ削除されて、1周ぴったりのループになります

9.7 格子(スクワッシュ&ストレッチ)

ボーンがなくても、格子で絵全体をつぶしたり伸ばしたりできます(スライムやボールなど)。

  1. ② 格子 モードにする
  2. 絵の上をドラッグして格子の範囲を作る(または「絵に合わせる」ボタン)。「分割 横・縦」で格子の細かさ(1〜6)
  3. ポーズ モードにすると、① のように格子の点(白丸)が出ます。点をドラッグすると、そのまわりの絵が伸び縮みします(今のフレームのキーになる)
  4. 「弾む」「待機(呼吸)」プリセットは、この格子を自動で作って動かします(③)
  • 格子はボーンと一緒に使えます(ボーンで歩かせながら、格子で体をつぶす、など)
  • 「格子を使う」のチェックを外すと格子の変形をやめます

9.8 ドット化・縁取りとリグ

  • ドット化した図形・レイヤーをリグで動かすと、ドット感を保ったまま動きます
  • 縁取りは作った時点の形をなぞったパスです。リグで動かすキャラには「選んだ図形ごとに別々に作る」で作ると、縁取りが各パーツのバインドを引き継いで一緒に動きます(6章)
  • アウトライン化した図形も、バインドを引き継いでそのまま動きます

9.9 困ったときは

症状 原因と対処

画像のトレース(色の境目を、線のパスに)

写真やイラストの色の境目(輪郭)をなぞって、線のパスにします。できるのは絵(ラスター)ではなくベクターの線なので、あとで1本ずつ選んで、点を動かす・太さや色を変える・消す、ができます。

取り込んだ画像から作る(おすすめ)

  1. 画像を取り込みます(「そのまま配置」)。
  2. レイヤーパネルで、その画像のレイヤーを選びます(取り込んだ直後は、選ばれています)。矢印ツール(V)か自由変形(T)にすると、上のバーに 「トレース…」(①)が出ます。
  3. 「トレース…」を押すと、確認の絵つきの画面が出ます。つまみを動かすと、すぐ結果が変わります。
つまみ 内容
感度 大きいほど、弱い境目(うすい色の差)も線にします
ぼかし 大きいほど、細かい模様やノイズを拾わなくなります。小さい絵・ドット絵は 0 に
なめらかさ 大きいほど、点が少なく、なめらかな線になります
短い線を省く これより短い線(px)は作りません(ごみのような線を減らす)
線の太さ できる線の太さ(あとで「線と塗り」で変えられます)
  1. **「パスを作る」**を押すと、画像の上に「○○(トレース)」というベクターのレイヤーができます。線の色は、そのときのメインカラーです。
  2. 元の画像がいらなければ、レイヤーの目のアイコンで隠すか、削除します。
  • 取り込むときに作る: 取り込みの画面で「輪郭を抽出(パス)」を選んでも、同じ線のパスになります(「元の画像も下に配置する」で、半透明の元の絵も入ります)。
  • 「トレース」のボタンは、レイアウトで、上のバーにいつも置いておくこともできます。
  • 大きい画像は、長い辺を 1200px に縮めてなぞります(線は、元の大きさに合わせて置かれます)。
  • 作った線を塗りの図形にしたいときは、線を選んで「アウトライン化」。囲まれた所に色を付けたいときは、塗りつぶしツール(4章のあいまいな塗り)。

12. 画像をパーツに分ける(AI)

キャラクターの絵(PNG・JPG)を読み込んで、顔・前髪・腕などをクリックするだけで、パーツごとのレイヤーに自動で分けます。分けたパーツはそのままリグ(9章)で動かせます。

  • AI(MobileSAM)はこのパソコンの中だけで動きます(インターネットに絵を送りません)
  • 初回だけ AI モデルを自動でダウンロードします(切り抜き用 約45MB、穴埋め用 約200MB)。2回目からはすぐ使えます
  • 使っているモデル(MobileSAM・LaMa)は商用利用できるライセンスです(Apache-2.0 / MIT)。分けた絵はゲーム素材などに使えます

12.1 使い方

  1. 「画像読込」(Ctrl+I)で絵を選ぶ(ウィンドウへのドラッグ&ドロップでも可)
  2. 「パーツに分ける(AI)」を選んで「取り込む」。サイズは「アートボードに合わせる」か「原寸」
  3. 下の画面が開きます。最初に数秒、AI が絵を解析します(④ に「準備できました」と出るまで待つ)

  1. ① のリストでパーツを選ぶ(選んだ行が青くなる)
  2. 絵の上のその部分を左クリック → AI がその部分を自動で切り抜いて、パーツの色で塗られます(リストに ✓ が付く)
  3. 余計な所まで入ったら、そこを右クリック(赤い − の点 = 除外)。足りなければ足りない所を左クリック(緑の + の点 = 含める)。点はいくつでも足せます
  4. Enter(または ③「次のパーツへ」)で、まだ切り抜いていない次のパーツへ。4〜6 をくり返す
  5. 全部できたら ⑤「レイヤーを作成」。パーツ名のレイヤーが追加されます(「隠れた部分を AI で埋める」がオンなら、先に穴埋めをします。12.4)
操作 内容
左クリック 含める点(緑の +)
右クリック 除外する点(赤の −)
Backspace / Ctrl+Z / ③「1つ戻す」 最後の点(または囲み)を取り消す
③「このパーツをやり直す」 そのパーツの点・囲みを全部消す
Enter / ③「次のパーツへ」 次のパーツを選ぶ
Esc / キャンセル 何も追加せずに閉じる

ペンで囲んで選ぶ(⑥ の切り替え)

選び方 内容
クリック(AI) これまでどおり。クリックした所の物を AI が切り抜く
囲む 画像の上を左ドラッグでぐるっと囲むと、囲んだ形そのままがパーツに入る。右ドラッグで囲んだ所を削る。AI がうまく分けられない所(髪の毛の先・つながった部分など)を手で決めたいときに

  • クリックと囲むは組み合わせられます(例: クリックで大まかに切り抜いて、はみ出した所を「囲む」の右ドラッグで削る)
  • 囲んでいる途中は、足すときは緑、削るときは赤の点線が出ます

12.2 パーツのリスト

  • はじめは「前髪・顔・右腕・左腕・胴体・右脚・左脚・後ろ髪」。名前はクリックして書き換えられます
  • ② で好きなパーツを追加(例: 帽子、しっぽ、武器)。✕ で削除
  • **リストの上にあるパーツほど前(上のレイヤー)**になります。▲▼ で順番を変えられます(後ろ髪は一番下、など)
  • 2つのパーツが同じ所を取り合ったときは、リストの上のパーツのものになります
  • 名前と順番は次回も使われます
  • 使わないパーツは切り抜かなければ、レイヤーは作られません

12.3 できるレイヤー

  • パーツごとに1枚のラスターレイヤー(名前 = パーツ名)
  • 「どのパーツにも入らない部分を「残り」レイヤーにする」がオンなら、残った部分(背景・ふちの線など)が「○○(残り)」レイヤーになります
  • 全部のレイヤーを重ねると元の絵とぴったり同じになります(すき間はできません)
  • 分けたあとは、9章の手順でボーンを作り、パーツごとに「○○から先」「○○に固定」でバインドすると動かせます

12.4 隠れた部分を AI で埋める

パーツを分けると、前のパーツ(例: 腕)に隠れていた後ろのパーツ(例: 胴体)の所は空白になります。 「隠れた部分を AI で埋める」(画面右下のチェック、はじめはオン)にしておくと、AI(LaMa)が周りの色や模様に合わせて自動で描き足します。リグで腕を動かしても、後ろに穴が見えません。

  • 埋めるのは「後ろのパーツの形の内側」だけです。腕が体の外にはみ出している所まで胴体を広げたりはしません
  • 時間がかかります(このパソコンで1か所 約7〜8秒。パーツの数・隠れている所の数だけくり返す)。「レイヤーを作成」を押したあと、進み具合が右上に出ます
  • 途中で「キャンセル」(または Esc)を押すと穴埋めだけ止めて、そこまでの結果でレイヤーを作ります
  • AI の準備(読み込みに十数秒)は、パーツをクリックしている間に裏で済ませます。チェックの横に「準備OK」と出ます
  • チェックを外すと穴埋めをしません(設定は次回も使われます)
  • 描き足すのは AI の推測です。細かい模様(しま・文字など)はぼんやりすることがあるので、気になる所はペンで手直ししてください

12.5 うまく分けるコツ

  • 輪郭の線(主線)が内側の色と別に取れることがあります。線まで含めたいときは、線の上も左クリック
  • 腕が胴体に重なっている絵では、胴体を選んだあと腕の上を右クリック(除外)すると分けやすくなります
  • 背景が透明な PNG のほうが、背景と一緒に切り抜かれにくくなります
  • 見えていなかった部分(腕の後ろの胴体など)は 12.4 の穴埋めで自動で描き足せます

13. フォント作成モード

自分でフォント(文字のデザイン)を作れます。作ったフォントは OTF ファイルとして書き出して、ほかのソフトやゲームで使ったり、このアプリの文字ツールでそのまま使ったりできます。

  • 上の「フォント作成」ボタンで始めます。フォントは新しいタブで開きます(「フォント」の印のタブ)。今の絵のタブはそのままで、上のタブで行き来できます。絵でコピーした図形を、字に貼り付けることもできます(3.7)
  • 「フォント作成を終わる」(またはタブの ×)でフォントのタブを閉じ、開いたときの絵のタブに戻ります。フォントのタブは、いくつでも同時に開けます
  • フォント作成中はタイムラインが消えて、キャンバスが広くなります。レイヤー・パレットなど絵のための機能も隠れます
  • 作りかけのフォントは「保存」(Ctrl+S)で .kodai ファイルにできます。そのファイルを開くと、フォント作成モードで開きます

  • 線で描いても大丈夫です。書き出すときに、線・塗り・重なった図形はすべて「塗りの形」にまとめられます(色は関係なく、見えている所が字になります)

  • ⑤「アプリに追加」→ すぐにこのアプリの文字ツール(3.6)のフォント一覧に出ます。作業の内容(字・筆の部品・設定)も一緒に取っておくので、あとで開いて直せます(13.7)
  • フォントに入っていない字は、ほかのソフトでは四角(□)などで表示されます
  • 日本語フォントは字の数がとても多いので、使う字だけ作るか、次の「文字の自動作成」を使います

13.5 文字の自動作成(漢字・かな・英数字。筆の部品を作れば全部の字に)

漢字は「骨組み(画の中心線・画の種類・書き順)」と「筆の癖(線の太さ・入り・止め・はね・払いの形)」に分けて考えられます。 このアプリは骨組みのデータ(KanjiVG、漢字・ひらがな・カタカナ・アルファベット・数字 約6700字)を持っているので、筆の部品を描くだけで、全部の字をその筆で自動で組み立てます。 漢字は6つの部品(横画・縦画・はね・左払い・右払い・点)、ひらがな・カタカナは「かな」の部品1本、アルファベット・数字・記号は「英数字」の部品1本で作ります。 部品を直すと、全部の字がすぐに変わります。

はじめ方: フォントのパネルの「文字の自動作成(漢字・かな・英数字)」→「文字の自動作成を始める」。初めてのときだけ骨組みのデータ(約3.6MB)をダウンロードします。 最初はゴシック風の部品が入っているので、すぐに字ができます。

番号 内容
① 筆の部品: 横画・縦画・はね・左払い・右払い・点(漢字用)と、かな(ひらがな・カタカナ用)・英数字(アルファベット・数字・記号用)。クリックするとその部品を描く画面になります
② 入り・終わりの長さ: 部品の書き始めと終わりの形を保つ長さ。この部分は伸び縮みせず、間だけ画の長さに合わせて伸びます(横画・縦画・かな・英数字)。0 と 0 にすると部品全体を画の長さに合わせて伸ばします(払い・はね・点)
③ 太さ(全部の部品の太さをまとめて変える)・字の大きさ
④ 画の種類ごとに部品を変える: 「㇐ 横」「㇑ 縦」「㇕ 横→縦」など、画の種類を選んで「作る」と、その種類の画だけに使う部品ができます(いまの部品を写して始まります)。× でやめると元の部品に戻ります
⑤ まとめて追加: アルファベット・数字・記号(A〜Z・a〜z・0〜9・! ? , . : ;)/ ひらがな / カタカナ / 漢字 JIS 第1水準(約3000字)/ 第1・第2水準(約6300字)。追加した字は自動で作られます

部品の描き方

  • 部品は横向きの1本の画として描きます。左が書き始め、右が終わり。赤い点線が画の中心線です
  • ペン・パス・多角形など、ふつうの図形ツールで描けます(色は関係なく、見えている所が形になります)
  • 部品は骨組みの線に沿って曲げて貼られます。横画では部品の下側がそのまま下側に、縦画では部品の下側が字の左側になります(書き始めの斜めの切り口などを描くときの目安)
  • 下にお手本の字(永・東・必 など)が並び、部品を直すとすぐに変わります
  • 折れる画(口の右上など)は、角の前後で横画・縦画の部品を使い分けて角で重ねます。はねのある画は、最後の短い部分を「はね」の部品で描きます

ひらがな・カタカナ・アルファベット・数字

  • かなと英数字は、曲がった画が多いので、向きで部品を使い分けずに専用の部品1本を画に沿わせて描きます。「かな」「英数字」の部品を描き直すと、その字だけがまとめて変わります(漢字はそのまま)
  • 部品を描いているときは、下のお手本がその字になります(かな = あ・の・を…、英数字 = A・R・S・a・g…)
  • アルファベット・数字は字ごとに幅が違います(I は細く、W は広く)。足したときに骨組みの幅から自動で決まり、あとから「幅」で変えられます。字は幅の中央に置かれます
  • アルファベット・数字はベースラインに乗り、大文字の高さは「大文字の高さ」の線に合います(g・p・y などは下に出ます)
  • 作れる記号は ! ? , . : ; だけです(ほかの記号は骨組みがないので、手で描きます)
  • 自動作成を使っているフォントでは、何も描いていないアルファベット・数字の字も自動で作られます。自分で描けば、その字は描いた形になります
  • 前の版(1.36.0 まで)で作ったフォントのファイルは、「かな」「英数字」の部品を作るまで、かなは今までどおり横画・縦画の部品で描かれます

1字だけ直したいとき

  • 字の一覧で字を選ぶと、パネルに「○は自動」と出ます。「手で直す」を押すと、その字だけ今の形が図形(画ごとのグループ)になり、ふつうに直せます
  • 手で直した字は、部品を変えても変わりません。「自動に戻す」で自動の字に戻ります
  • 字の一覧で、自動の字は小さい文字が青で表示されます

ドットのフォントでも使えます。組み立てた字をマス目に合わせてドットにします(マス目が少ないと画がつぶれやすいので、16 以上がおすすめ)。

13.6 画像から字を取り込む(ロゴや手書きの字をフォントに)

ロゴの画像や、紙に書いて撮った字の画像から、字を1つずつ切り分けてフォントの字形にします。 画像にない字も、画像の字から「筆」を取り出して、まとめて作れます(数文字のロゴから、A〜Z・a〜z・数字のそろったフォントに)。

はじめ方: 「フォント作成」の最初の画面で「画像から作る…」、またはフォントのパネルの「画像から字を取り込む…」(今のフォントに足す)。

番号 内容
① 画像を選ぶ…: PNG・JPEG・WebP など。字と背景の色がはっきり違う画像が向いています(背景が透明の画像は、色の付いた所が字になります)
② 確認の絵: 見つけた字を1字ずつ色を変えて表示します。上に、当てはめた字が出ます。青い線 = 上の線、赤い線 = ベースライン。灰色の所は取り込みません
③ 字(左から順に): 画像の字を、左から(何段かあれば上の段から)順に入力します。例: VOLKENO
④ 字の色(自動 / 明るい字 / 暗い字)と濃さの境目: 字がうまく拾えないときに変えます。境目を上げると薄い色(かすれ・別の色の飾り)が外れ、下げると拾います
⑤ 上の線・ベースライン: この2本の間が、フォントの「大文字の高さ」になります。自動で、字のいちばん濃い帯に合わせます。飾りや、下に伸びた線は帯の外にはみ出したまま取り込まれます
⑥ 画像にない字も作る: 作る字の組(英大文字・英小文字・数字と記号・ひらがな・カタカナ)、筆にする画、太さ。下の「画像にない字も作る」を見てください

字の分かれ方を直す

  • 1字が2つのかたまりに分かれている字(K の縦棒と斜めの線が離れている、など)は、入力した字の数に合うように、すき間の狭い所から自動でつなぎます
  • 違っていたら、確認の絵で右側のかたまりをクリックすると前の字につながり、もう一度クリックすると分かれます。「自動でまとめ直す」で元に戻ります
  • 小さなかけら・点・しずくは、いちばん近い字に付きます(遠いものは取り込みません)
  • 字どうしがつながっている(筆記体など)画像は、1字に分けられません

画像にない字も作る(筆を取り出して、残りの字をまとめて作る)

  • 画像の字の中からまっすぐな縦の画(I や、L・K の縦棒など)を1本選び、それを「筆」にして、画像にない字を 13.5 文字の自動作成 の仕組みで作ります
  • 似る所: 線の太さ・かすれ・ふちの荒れ・端の形(セリフ)。似ない所: 字ごとの飾り、長く伸びた払い、線の太い細いの差(横の線だけ細い書体など)。作った字は、線の太さがそろった素直な形になります
  • 「筆にする画」は自動で選びますが、ほかの候補に変えられます(右に、取り出した筆が出ます)。「太さ」で、画像の字と見た目の重さをそろえます
  • 画像の字(取り込んだ字)はそのまま残り、画像にない字だけが作られます。新しいフォントでは、はじめからオンです
  • ひらがな・カタカナ・漢字(JIS 第1水準)も、同じ筆で作れます(作る字の組で選ぶ)。あとから「文字の自動作成」の「まとめて追加」で足しても、同じ筆で作られます(筆の部品が「英数字」だけのフォントでは、かな・漢字もその筆で描きます。漢字は、とめ・はね・払いの区別のない形になります)
  • 作った字は「文字の自動作成」の字です。あとから筆の部品「英数字」「かな」を描き直したり、「太さ」を変えたりすると、まとめて変わります。1字だけ直すときは「手で直す」
  • 初めてのときだけ、骨組みのデータ(約3.6MB)をダウンロードします。フォントのファイルを配るときのライセンスは 13.5 と同じです(KanjiVG、CC BY-SA 3.0)
  • すでに「文字の自動作成」で自分の筆を作っているフォントでは、筆の部品「英数字」(かなを選べば「かな」も)が置き換わるので、はじめはオフになっています

取り込んだあと

  • 字は**ふつうの字形(パスの図形)**になるので、ペンやダイレクト選択で直せます。ドットのフォントでは、マス目のドットになります
  • 字の幅は、画像での次の字までの距離をそのまま写します(同じ並びで打つと、元のロゴと同じ字間になります)。あとから「幅」で変えられます
  • もうある字を取り込むと、形と幅が置き換わります。同じ字が画像に2回あるときは、最初のものを使います
  • 「画像にない字も作る」をオフにしたときは、画像にある字だけが入ります
  • 取り込みは「元に戻す」で取り消せます

ほかの人が作ったロゴやフォントの画像から作るときは、その字を使ってよいか(権利)を確かめてください。

13.7 作ったフォントを開いて直す

「アプリに追加」したフォントは、あとから開いて、字を足す・入れ替える・直すことができます。

  1. 「フォント作成」→「もとにするフォント」で、直したいフォントを選ぶ →「作る」(画像の字を足す・入れ替えるなら「画像から作る…」)
  2. 字を直す。画像から足すときは、パネルの「画像から字を取り込む…」(13.6)。もうある字は、新しい形に入れ替わります
  3. 「アプリに追加」→ 同じ名前のフォントが、直した内容に置き換わります(番号の付いた別のフォントにはなりません)

「もとにするフォント」には2種類が出ます。

種類 内容
作ったフォントを開いて直す Kodai で作って「アプリに追加」したフォント(1.40.0 から)。字・筆の部品・自動の字・設定が、そのままの形で開きます
入れてあるフォントの輪郭を読み込む 作業の内容が取っていないフォント(前の版で作ったもの、「フォントを追加」したファイル)。字の輪郭だけを図形として読み込みます。自動の字もふつうの図形になり、筆の部品はありません。字の多いフォントは先頭の 3000字まで。「アプリに追加」すると、新しいフォントとして入ります

14. Claude 連携(Claude に作ってもらう)

Claude Code(AI のアシスタント)から Kodai を操作して、絵・ドット絵・テクスチャ・簡単なアニメーションを作ってもらえます。 「Kodai で 32px の剣のドット絵を作って、8倍で PNG に書き出して」「64px の継ぎ目なしの石畳を3種類作って」のように、ふつうの言葉で頼みます。

  • 絵を作る処理は、この PC の中の Kodai が行います。画像生成 AI や外部のサービスは使いません(Claude が「何をどう描くか」を考える分は、ふだんの Claude の使用量としてかかります)
  • 作ったものはふつうの Kodai の絵です。Ctrl+Z で戻せて、.kodai で保存すれば自分で手直しできます

14.1 はじめに(1回だけ)

  1. Kodai の「ファイル → Claude 連携…」を開く
  2. ① **「Claude 連携をオンにする」**にチェック(下のステータスバーに緑の「● Claude 連携」が出ます)
  3. ② **「自動で登録する」**を押す。Claude Code に Kodai がつながり、Kodai の使い方メモ(スキル)も入ります
    • うまくいかないときは、③ のコマンドを「コピー」して、ターミナル(PowerShell など)で1回実行します
  4. 新しく開いた Claude Code で頼みます(登録の前から開いていた Claude Code では、つなぎ直すか開き直します)

ダイアログのいちばん上に、今の登録の状態が出ます。「● 登録済み(Kodai を閉じていても使えます)」なら OK です。 「▲ 登録がずれていて、つながりません」「▲ 前の方式で登録されています」と出たら、「自動で登録する」をもう一度押してください。

1.40.0 までに登録した人へ: 前の方式は、合言葉を Claude Code の側にも書き込んでいたので、Kodai の側と食い違うとつながらなくなりました。 1.41.0 の「自動で登録する」を1回押すと、新しい方式(合言葉を書き込まない・Kodai を閉じていても使える)に変わります。

14.2 使うとき

  • Kodai は閉じていてもかまいません。Claude が Kodai を使うときに、Kodai が画面を出さずに裏で起動します(タスクバーにも出ません)
    • そのあと Kodai をふつうに開くと、裏で動いていた Kodai の画面がそのまま出ます(Claude が作っていた絵も見られます)
    • 裏で起動した Kodai は、20分 使われないと自動で終わります(保存していない絵があるときは終わりません)
    • Claude Code を開いただけでは、Kodai は起動しません(Kodai の道具を初めて使ったときに起動します)
  • Kodai を開いているときは、今までどおり、開いている Kodai を Claude が操作します
  • Claude が操作している間は、Kodai の画面に「Claude: 図形を描く」などと出て、絵がその場で変わっていきます
  • Kodai でダイアログを開いていると、Claude は待たされます。閉じておいてください
  • 保存していない絵があると、Claude は勝手に新しい絵にしません(先に聞いてきます)

14.4 安全のしくみ

  • Kodai はこの PC の中からだけつながります(ほかの PC やインターネットからはつながりません)
  • つなぐには**トークン(合言葉)**が必要です。トークンはコマンドに入っているので、人に見せないでください。漏れたときは「トークンを作り直す」を押して、もう一度登録します
  • Web ページ(ブラウザ)からの操作は断ります
  • Claude が読み書きできるファイルは、Claude が指定したものだけ(.kodai・.png・.gif など決まった種類)です
  • やめるときは「Claude 連携をオンにする」のチェックを外します。Claude Code からも消すときは、ターミナルで claude mcp remove kodai --scope user
